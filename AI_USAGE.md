# AI usage

**Claude Code (Claude Opus 5.5, Anthropic)** was the main tool. It worked as a coding support under my
direction. It:
- read the paper and its released logs;
- wrote the code (`src/`, `numword/src/`, `swthink/`);
- launched and monitored the GPU jobs;
- produced the analysis, figures and drafts of the research note and report.

I set the scope and reviewed the design decisions, the results and the conclusions.

**Time and compute.** The main study (H2, H3) ran on 19 November, over about 3 hours. Agents ran GPU jobs
in parallel on two single-GPU workstations. The assignment's 4-hour target covers the experiment (H2, H3);

Claude Code turned the hypothesis into pre-registered experiments and ran them. It also found the number-word misreadings and
the tokenizer splits behind them in the existing outputs. During the H2 runs it caught and fixed two flaws in its own
design: random twins that were not norm-matched, and a training format that made the trained edits answer in one
line. The self-distilled C2/D2 runs that followed are marked exploratory.

1. **Synthetic prompts.** They wrote the Swedish, English, Danish and Norwegian chat prompts in `data/prompts/` and
   validated them by script.
2. **Translation.** They translated GSM8K problems into Swedish: 200 TEST and 300 TRAIN/DEV problems, in
   `data/gsm8k/`.
   - A script checks that every number in the English problem appears in the Swedish version.
   - No external translation API was used.
   - These are LLM translations, spot-checked but not professionally reviewed.
3. **The weight programmer as a subject.**  It
   received the weights and a budgeted harness with 0 forward passes, mirroring the paper's use of GPT-6 Astra. Its
   code and answers are archived in `wsp/runs/`. Its one testable idea, that the presence penalty hurts
   Swedish, was tested separately and did not hold.
4. **Edit-rank study.**    
  - It wrote its pre-registration before training and logged every later change in
     `rank_study/logs/decisions.log`.
   - For one side check it translated English GSM8K TRAIN solutions into Swedish. These are unreviewed LLM
     translations, and the check was not used for the main result.

**What AI was not used for.**
- No AI model graded any result. All accuracy numbers come from exact-match graders (`src/grade_math.py`,
  math-verify) and from log-probabilities.
- The synthetic number-word problems of H2 (`numword/data/`) were generated by a script from templates, not by an
  LLM.
- Open-weight models were used only as experimental subjects (Qwen3.5-0.8B and the models in the language scan;
  licences in `README.md`).

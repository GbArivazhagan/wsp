# Source of this folder

A small, unmodified subset of <https://github.com/RikiyaT/lm_understand-logs>, the released logs of *Sparks of
Weight-Space Programming* (Takehi et al., 2026), copied on 2026-11-18 from `main` at commit
`4d09ba6d6a7e891dd8063974dfe81b3d78e3494f`:
- `exp8_math/code/` — the authors' `apply_edit.py` and its helper;
- `exp8_math/runs/p50c/edit/` — the paper's p50c edit;
- `exp8_math/runs/p50c/work_notes/experiment_history.md` — the run's notes, cited in our critique.

Licences: see `LICENSE` in this folder (logs and data CC BY 4.0; the authors' scripts MIT; third-party benchmark
content keeps its own licence). We use the code and the edit to rebuild the paper's edit exactly
(`scripts/build_paper_edit.sh`).
